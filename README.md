# 🩸 Blood Donation Network

A Python-based Blood Donation Management System developed using Streamlit.

This project helps hospitals efficiently manage blood donors, record blood donations, and send emergency blood requests through email notifications. The system includes separate dashboards for Admin and Hospitals with secure login functionality and donor management features.

---

# Features

## Admin Panel
- Secure Admin Login
- Register Hospitals
- View Registered Hospitals
- Delete Hospitals
- Monitor Blood Donation Network
- Track Total & Eligible Donors

## Hospital Dashboard
- Secure Hospital Login
- Add New Donors
- Record Blood Donations
- Send Emergency Blood Requests
- View Donor Database
- Delete Donors

## Donor Management
- Blood Group Filtering
- City Filtering
- CNIC Validation
- Gmail Validation
- Phone Number Validation
- 90-Day Eligibility Rule

## Email Notification System
- Emergency Blood Request Emails
- Gmail SMTP Integration
- Automated Donor Notification System
